# AthletiQ MVP Scope

## MVP Capabilities

- Organizer login.
- Create sports event.
- Build custom form.
- Configure selection criteria.
- Publish application link.
- Players apply.
- Applications stored.
- Objective scoring.
- AI-assisted evaluation.
- Rank players.
- Live organizer dashboard.
- Shortlist.
- Select.
- Send official email.
- Player accept/decline.
- Automatic dashboard updates.
- Final selected-player list.
