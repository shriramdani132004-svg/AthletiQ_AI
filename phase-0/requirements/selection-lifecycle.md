# Selection Lifecycle

## Main Flow

Applied
→ Validated
→ Evaluated
→ Ranked
→ Shortlisted
→ Selected
→ Email Sent
→ Awaiting Response
→ Accepted / Declined
→ Finalized

## Organizer Decisions

Organizer may:
- Shortlist.
- Remove from shortlist.
- Select.
- Reject.
- Remove.
- Restore where permitted.
- Record decision reason.

## Candidate Response

Selected candidate receives:
- Event information.
- Selection notification.
- Secure accept action.
- Secure decline action.

## Response Flow

Email
→ Secure Token
→ Token Validation
→ Candidate Response
→ Database Update
→ Real-Time Event
→ Organizer Dashboard

## Finalization

Accepted players may move into the final selected-player workspace.

Declined players may be replaced according to organizer workflow.

## Decision Integrity

Selection decisions should contain:
- Candidate.
- Event.
- Organizer.
- Decision.
- Timestamp.
- Reason where applicable.
