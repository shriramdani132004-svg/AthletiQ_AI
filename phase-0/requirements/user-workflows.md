# AthletiQ User Workflows

## Organizer Workflow

1. Register.
2. Login.
3. Create sports event.
4. Define requirements.
5. Build application form.
6. Configure evaluation criteria.
7. Preview.
8. Publish.
9. Generate link/QR.
10. Monitor applications.
11. Review validated applications.
12. Run objective evaluation.
13. Run AI-assisted evaluation.
14. Review rankings.
15. Shortlist candidates.
16. Select candidates.
17. Send official communication.
18. Monitor accept/decline responses.
19. Finalize selected players.

## Player Workflow

1. Open event link or QR.
2. Read event information.
3. Review eligibility.
4. Complete application.
5. Upload required information/documents.
6. Submit application.
7. Receive confirmation.
8. Wait for evaluation.
9. Receive official communication.
10. Accept or decline securely.
11. Response appears in organizer dashboard.

## Staff Workflow

1. Authenticate.
2. Access permitted event.
3. Review assigned candidates.
4. Perform permitted evaluation/selection actions.
5. Maintain decisions within granted permissions.

## Super Admin Workflow

1. Authenticate.
2. Access administration.
3. Maintain platform-level controls.
4. Support governance.

## End-to-End
