# Application Lifecycle

## Primary Lifecycle

APPLIED
→ VALIDATED
→ EVALUATED
→ SHORTLISTED
→ SELECTED
→ EMAIL_SENT
→ AWAITING_RESPONSE
→ ACCEPTED / DECLINED
→ FINALIZED

## Additional States

REJECTED
REMOVED
WITHDRAWN
ARCHIVED

## State Definitions

### APPLIED
Application has been submitted.

### VALIDATED
Application passed validation and duplicate checks.

### EVALUATED
Objective and/or AI-assisted evaluation completed.

### SHORTLISTED
Candidate identified for further consideration.

### SELECTED
Candidate selected by organizer.

### EMAIL_SENT
Selection communication issued.

### AWAITING_RESPONSE
Selected player has not responded.

### ACCEPTED
Player accepted selection.

### DECLINED
Player declined selection.

### FINALIZED
Candidate finalized in the selected-player list.

### REMOVED
Candidate removed with state and reason preserved.

## Status History

Important transitions must be represented as historical events for traceability.
