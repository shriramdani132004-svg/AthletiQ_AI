# Privacy Requirements

## Candidate Data

Potentially sensitive information includes:
- Identity.
- Contact information.
- Sports information.
- Experience.
- Achievements.
- Performance information.
- Application answers.
- Documents.
- Photos.
- Evaluation results.

## Requirements

- Collect only required information.
- Associate data with its recruitment purpose.
- Restrict access by role and resource permissions.
- Protect credentials.
- Protect candidate documents.
- Prevent private information exposure through public APIs.
- Record appropriate consent where required.
- Define retention/deletion rules before production.
- Protect internal AI evaluation details.

## Public

- Published event information.
- Public application form.

## Private

- Submitted applications.
- Candidate documents.
- Evaluation.
- Ranking.
- Organizer decisions.
- Communication history.

## AI Privacy

AI receives only information required for the configured evaluation task.

AI output remains within authorized access.
