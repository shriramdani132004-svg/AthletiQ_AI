# Event Lifecycle

## States

DRAFT
→ PUBLISHED
→ APPLICATIONS_OPEN
→ APPLICATIONS_CLOSED
→ SELECTION
→ COMPLETED
→ ARCHIVED

## DRAFT

Organizer is configuring the event.

## PUBLISHED

Event is published for recruitment.

## APPLICATIONS_OPEN

Players may submit applications.

## APPLICATIONS_CLOSED

New applications are no longer accepted.

## SELECTION

Organizer evaluates, ranks, shortlists and selects candidates.

## COMPLETED

Selection process has finished.

## ARCHIVED

Event is retained as historical information and is no longer active.

## Actions

- Create.
- Edit.
- View.
- Publish.
- Pause applications.
- Reopen applications.
- Close applications.
- Archive.
- Duplicate.

## Event Data

- Name.
- Sport.
- Description.
- Location.
- Start date.
- End date.
- Registration deadline.
- Required player count.
- Age/category requirements.
- Eligibility criteria.
- Rules.
- Image/banner.
- Status.
