# AthletiQ User Roles

## Target Users

1. Sports organizers.
2. Recruitment staff.
3. Players/candidates.
4. Platform administrators.

## SUPER ADMIN

Platform-level administrator.

Responsibilities:
- Platform administration.
- Platform configuration.
- System-level oversight.
- Platform support and governance.

## ORGANIZER

Primary business user.

Responsibilities:
- Create and manage events.
- Define requirements.
- Build application forms.
- Configure evaluation criteria.
- Publish events.
- Review applications.
- Evaluate candidates.
- Rank candidates.
- Shortlist candidates.
- Select candidates.
- Reject candidates.
- Send communication.
- Manage selected players.

## STAFF

Organizer-support role.

Responsibilities:
- Access permitted organizer workflows.
- Review assigned candidates.
- Assist with evaluation and selection.
- Operate within granted permissions.

## PLAYER

Candidate/applicant.

Responsibilities:
- Access published recruitment event.
- Submit application.
- Provide required information.
- Upload permitted documents.
- Receive communication.
- Accept or decline selection.

## Authorization Rule

Authentication
→ Role
→ Permission
→ Resource Ownership / Access

## Public Access

Published event/application pages may be publicly accessible when intentionally published.

Private candidate information must remain protected.
