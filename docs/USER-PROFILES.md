# AthletiQ User Profile Management

## Organizer Profile

Organizer profile capabilities:

- View profile
- Update profile
- Change password
- Email preferences
- Organization information
- Profile photo

## Authorization

Profile operations are available only to the authenticated user owning the profile.


## Player Profile

The full Player profile is intentionally deferred to the future/full version.


Future Player profile areas:

- Personal information
- Sports information
- Experience
- Achievements
- Performance records
- Documents
- Profile management
