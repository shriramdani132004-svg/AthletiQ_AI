# FORM VALIDATION

## Purpose

Validate organizer-configured fields before form data is accepted.

## Validation

- Required fields
- Number ranges
- Text length
- Regular expression patterns
- Email format
- URL format
- Rating range
- Selection options
- File size
- File extension

## Supported Field Types

- TEXT
- NUMBER
- EMAIL
- PHONE
- DATE
- DROPDOWN
- RADIO
- CHECKBOX
- MULTI_SELECT
- RATING
- FILE
- IMAGE
- URL
- LONG_TEXT

## Version Safety

Validation configuration belongs to the form field definition.

Published form versions remain immutable.

Only draft versions may be edited.
