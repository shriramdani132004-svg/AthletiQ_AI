# Phase 4 Event Frontend

## Implemented

- Event API client
- Organizer event listing
- Event status display
- Publish control
- Application open control
- Application pause control
- Application reopen control
- Application close API support
- Archive control
- Duplicate control
- Authenticated API requests

## Security

The frontend sends the existing AthletiQ access token with event requests. Authorization and organizer ownership remain enforced by the backend.
