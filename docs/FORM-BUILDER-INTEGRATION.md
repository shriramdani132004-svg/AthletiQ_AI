# FORM BUILDER COMPONENT INTEGRATION

## Integrated Components

- FormBuilderPage
- FormBuilderWorkspace
- FormFieldCard
- FieldConfigurationPanel
- FieldOrderList
- FormPreview
- fieldValidation
- fieldOrderUtils
- fieldOrderApi

## Workspace Responsibilities

- Display form fields
- Configure selected field
- Validate field configuration
- Reorder fields
- Preview the form
- Edit fields
- Duplicate fields
- Delete fields

## Immutability Rule

Published form versions remain read-only.

Only draft form versions may expose editing operations.
